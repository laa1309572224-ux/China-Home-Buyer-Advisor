# 西安 · 重庆购房监控与决策助手

零第三方依赖、数据本地保存的双城购房监控台：房源导入、挂牌价格快照、成交价对照、可解释评分、城市切换和等额本息贷款测算。

## 运行

Windows 双击 `启动购房助手.cmd`，或执行 `python app.py`，打开 <http://127.0.0.1:8766>。首次启动会载入明确标记的西安、重庆演示数据。点击“西安 / 重庆 / 全部”切换整张看板。

## 导入真实数据

页面支持 JSON 数组，必填 `title`、`total_price`（万元）、`unit_price`（元/㎡）、`area`（㎡）。建议同时提供 `source_url`、`city`、`district`、`community`、`year`、`commute_minutes`、`school_score`、`risk_score`。相同 `source_url` 再次导入会更新房源并保存当天价格快照。

`POST /api/collect` 支持链家/贝壳 HTTPS 单房源链接。平台可能要求登录或改变页面结构；系统不绕验证码、不读取浏览器 Cookie、不做高频批量请求。

## 方法与技能来源

- `waugustus/lianjia-spider`：借鉴 SQLite 每日快照、价格变化和已售迁移思路；没有复制旧页面解析代码。
- `MorvanZhou/zhongjie`（MIT）：借鉴需求画像、条件分层、矛盾识别和带理由推荐流程。
- `zjunlp/SkillNet`（MIT）：借鉴技能发现、来源、评价和路由记录方式。外部技能许可证独立，因此没有批量打包未知技能代码。
- SkillNet/GitHub 检索到的贷款技能大多绑定境外法规，不适合直接套用中国购房。本项目只复用通用输入校验、LTV/还款压力和风险声明思路。

## 口径

评分 = 预算 32% + 通勤 26% + 楼龄 14% + 教育 14% + 风险 14%。80 分以上“优先看房”，65–79.9“保留比较”，其余“谨慎考虑”。贷款默认等额本息 30 年，不含税费、中介费、公积金组合贷和未来利率调整。

内置成交记录全部标记为演示样本。导入官方或可信来源后，才能用于真实决策。此工具不是房价预测、贷款审批、法律或金融建议。
